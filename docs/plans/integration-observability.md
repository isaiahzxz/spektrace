## Design / local threat review
- Explicit fetch wrapper, no global instrumentation. Fixed integration/provider/environment and operation template; bodies/headers/URLs off by default. Sampling and queue drops reported. Opt-in response projection permits only configured conservative JSON pointers and presence/types; cap body reads, depth/count/bytes and duration. Never collect values, auth, cookies, user identifiers or URL query segments. Correlation requires explicitly supplied nonsecret IDs; do not infer identity from auth/header values.
- Extend DB with scoped immutable observation, versioned baseline, workflow outcome/link and coverage records. Ingestion tokens cannot administer baselines; admin auth cannot ingest. Server derives workspace and pins baseline at acceptance. Every retry uses immutable logical IDs; changed content conflicts. New records/work items commit atomically on the existing outbox. No silent historical fallback.
- Baselines are explicit immutable versions: observed selected shapes and supported stored OpenAPI response-schema provenance stay distinguishable. Published-contract provenance is operator supplied, not independently provider verified. Capture-off, incomplete, different policy or timeout produce unsupported/no-response, never invented drift. Supported shape changes are structural evidence, not business failures.
- Outcomes are final attempt events, explicitly correlated within workspace/integration/environment. Retries distinguish logical execution and attempt; late events do not overwrite newer attempts. Unmatched/truncated links and coverage are visible. Association is not causation. Bounded queries/locks, no raw errors/model input export. Local manual retention only; no automatic purge claimed.
- Read-only investigation shows baseline origin, selected changes, related calls/operations, linked outcome attempts, unmatched/partial coverage, alternative explanations and optional link to the retained request detector. Deterministic evidence only; no new AI call, correction, replay, messaging, support tickets or production exposure.
