# Sender Identity

Outcome: preserve a canonical sender only when an authenticated collector has an explicit scoped binding. Headers remain reported/unverified. Sender matching does not change contract selection, validation, grouping, AI, approvals or severity.

Use nonsecret UUID aliases from application authentication context; never read/hash/store authentication secrets. Exact workspace+collector credential+service+environment+principal kind+principal reference binding. Integration attestation is not independent SpekTrace verification of the original caller. Canonical registry keys are workspace-scoped. Mapping targets and incident snapshots are immutable; revocation affects future events. Tombstones never reactivate. Import/resolve/revoke use consistent credential→event(if ingest)→binding-scope locks, plus row locks, including absence semantics. Duplicate event identity remains unchanged; altered claim or collector credential conflicts. Legacy rows stay unrecorded.

Slices: schema/mapping import and service tests; ingestion resolution and boundaries; Express auth-context callback with untrusted-header separation; disposable verification, build and bounded local installation. Security threat model completed before implementation; no remaining founder decision blocks this slice.

Verify exact-scope isolation, spoofing, revocation races, immutable retries/late mappings, UUID normalization, callback failures and real middleware HTTP forwarding. Run full unit suite only inside a disposable DB wrapper because an existing unit harness resets its database. No shared DB reset, real company input, model calls, tickets or Slack. Historical regression remains required.

Status: implemented, verified and installed locally. 386 unit tests, 37 integration tests (14 sender, 12 historical, 9 credential, 2 application adapter), typecheck, changed-source lint and production build passed. Source-isolated controls caught both unsafe historical fallback and spoofed-header identity upgrade. Express 0.2.0 was packed and installed offline into a disposable consumer; its real HTTP forwarding path passed. Local additive migration applied with existing records unchanged and zero bindings; app/worker restarted and smoke checks passed. Separate live Express 0.1.0 demo remains unchanged. No real application identity source or company is connected. Stop here before sender grouping.
